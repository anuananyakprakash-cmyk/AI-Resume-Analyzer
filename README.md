# AI-Resume-Analyzer

## Project Overview
The AI Resume Analyzer and Job Recommendation System is a Python-based application that uses Natural Language Processing (NLP) and text similarity techniques to analyze resumes and recommend suitable job roles.

## Features
- Upload resumes in PDF and DOCX formats.
- Extract and process resume text.
- Identify skills mentioned in the resume.
- Recommend suitable job roles with match scores.
- Identify missing skills for selected roles.
- Provide a basic learning roadmap.
- Display results through a Streamlit interface.
- Download analysis results as a CSV file.

## Technologies Used
- Python
- Streamlit
- Pandas and NumPy
- Scikit-learn
- NLP and text similarity
- PyPDF
- python-docx
- Plotly and Matplotlib

## How to Run
1. Install the required libraries:
   `pip install -r requirements.txt`
2. Run the application:
   `streamlit run app.py`

## Disclaimer
Match scores are estimates for educational and career guidance only. They should not be used as the sole basis for hiring decisions.
